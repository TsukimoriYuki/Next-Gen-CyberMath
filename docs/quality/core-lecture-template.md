# 中核講義テンプレート（AM-GM密度を基準に）

Deep Research評価で「AM-GM講義は比較的高評価」「今後の中核講義はこの密度を基準にする」と
指摘された。このドキュメントは、AM-GM講義（`src/data/lessons/am-gm-inequality.ts`）の
構成を分析し、他単元の中核講義を書くときのテンプレートとして固定するためのものである。

**今回このテンプレートに沿って全講義を書き直すことはしない。** テンプレート化と、
次に手動作成すべき講義候補のリスト化までを行う（優先順位は `/quality/roadmap` 参照）。

## AM-GM講義の構造分析

`AM_GM_INEQUALITY_LESSON`（`Lesson` 型）は3層構成になっている。

| フィールド | 役割 | AM-GMでの内容 |
|---|---|---|
| `content` | 概要（一覧カード・ページ冒頭） | 定義式の提示 + 「この授業の目標」（証明の暗記ではなく理解） |
| `proof`（真理） | 厳密な証明 | 定理の明示 → 2乗の非負性からの証明 → 等号条件の精密確認 → **証明の構造を俯瞰する**（同値変形の連鎖を図示）→ **重要な変形型**（$a+k/a$ 形への一般化）→ **n変数への一般化** |
| `application`（極意） | 実戦での使い方 | 「見抜く技術」の明言 → 番号付き**思考フロー**（Step 1/2/3、具体例を通しで使う）→ **陥りがちな罠と対策**（表形式）→ **応用パターン速見表**（表形式）→ 締めの一言 |
| `practiceProblemSlug` | 確認問題への導線 | 実際の問題ページへの相互リンク |

密度が高いと感じさせている要素は、単なる文章量ではなく次の5点である。

1. **判別フロー（思考フロー）が番号付きのステップで、実際の例題を通しで解きながら進む**
   （フローと例題が分離していない）
2. **誤答分析が表形式**（罠 → 症状 → 対策の3列）で、読み手が自分の失敗パターンを検索できる
3. **応用パターンの速見表**があり、初見の類題でもテンプレートに当てはめて即答できる
4. **一般化・変形型が「証明」の一部として明示され**、応用の土台がどこにあるか分かる
5. **等号成立条件など、答案として不完全になりがちな部分を明示的に指摘する**一文がある

## 中核講義テンプレート（13項目）

新しく中核講義を書く、または既存の「満点講義」（`src/data/specialLectures.ts`）を
書き直すときは、以下の13項目を目安にする。すべて必須ではないが、抜けている項目は
「今回は省略した」と自覚したうえで省略すること。

1. **何を扱うか** — 単元・テーマの一文要約
2. **なぜ重要か** — この単元でつまずくとどこで失点するか
3. **定義・定理** — 数式で厳密に提示する
4. **公式の導出** — 暗記ではなく、なぜ成り立つかを証明する
5. **使いどころ** — どんな見た目の問題でこの武器を使うか
6. **判別フロー** — 番号付きステップ。実際の例題を通しで解きながら進める
7. **代表例題** — 判別フローの中で使う具体例（別枠にしない）
8. **別解** — 少なくとも1つ、視点の異なる解法を示す
9. **よくあるミス** — 表形式（症状 → 原因 → 対策）
10. **時短ポイント** — 本番で使える近道・検算方法
11. **発展への接続** — 変形型・一般化・他単元との接続
12. **確認問題** — 実際の問題ページへの相互リンク（`practiceProblemSlug` / `relatedProblems`）
13. **復習先** — つまずいたときに戻るべき単元・タグ

`specialLectures.ts` の `LectureBlock` 型には、この大半に対応するブロックが
既に存在する（`solutionFlow` = 判別フロー、`mistakeRecovery` = よくあるミス、
`discriminationDrill` = 判別ドリル、`checklist` = 確認事項、`relatedProblems` = 確認問題）。
既存4本の `mistakeRecovery`/`discriminationDrill` は実際に中身が書かれている
（空のプレースホルダーではない）。ただし `explanationTabs` の内訳を数えると、
「ヒント/方針/詳しい解説」系のタブが15箇所に対し「最速解法/類題」（別解に近い内容）は
9箇所と、別解・別視点の比重が相対的に薄い。
**インフラは既にあるので、次にやるべきは新しいブロック型の実装ではなく、
既存ブロックへの中身の拡充（特に別解の比重を上げること、一般化・発展への接続の明記）である。**

## 次に手動作成すべき中核講義の候補

すでに実在する「満点講義」（`MASTERY_LECTURE_GUIDES` で問題ページから参照される）を、
このテンプレートの密度まで引き上げることを優先する。新しい単元の講義を増やすことより、
既存4本の質を上げることを先にする。

| 優先度 | 対象講義 | slug | 対象単元 | 状態 |
|---|---|---|---|---|
| 1 | 図形と計量 満点講義 | `geometry-measurement-intensive` | 図形と計量 | 適用済み（2026-07-02） |
| 2 | 図形の性質 満点講義 | `geometry-properties-auxiliary-lines` | 図形の性質 | 適用済み（2026-07-02） |
| 3 | 確率 満点講義 | `probability-guided-reading` | 場合の数と確率 | 適用済み（2026-07-03） |
| 4 | 二次関数 満点講義 | `quadratic-case-split-intensive` | 2次関数 | 適用済み（2026-07-03） |
| 5 | データの分析 満点講義 | `data-analysis-quartiles-outliers` | データの分析 | 適用済み（2026-07-03） |

各講義で特に補強すべき項目（テンプレート項目8・9・11に対応）:

- **別解**: 現状、単一の解法ルートで完結している設問が多い。代表例題ごとに、
  少なくとも1つ別の視点（幾何的 / 代数的 / ベクトル的など）を追加する。
- **誤答分析**: `mistakeRecovery` ブロックの中身を、実際の失点パターンに基づいて
  表形式で拡充する。
- **一般化・発展への接続**: 各講義の終盤に、共通テストの枠を超えた発展的な扱い
  （数学II・B・C以降での再登場、なぜこの技法が汎用的か）を一文添える。

これらの中核講義と合わせて、対応する代表例題（問題）を1〜2問ずつ選定し、
このテンプレートに沿った解説を書き下ろす。

データの分析については、模試復習に必要な四分位数・外れ値・平均値/中央値に絞り、
相関係数や仮説検定へは広げすぎない方針で別途中核講義化した。
