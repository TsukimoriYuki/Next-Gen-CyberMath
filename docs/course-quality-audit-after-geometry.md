## 1. 総評

`geometry-properties`（図形の性質）の完成により、**「このサイトが目指す高品質講座とは何か」が初めて具体物として確定した**。図解（diagram 15枚）・読み替え表・段階別例題・NG/OK 形式の誤答・確認問題が揃い、導出から方針判断まで通すこの単元が、全講座の到達目標（S 基準）になる。

一方で、その S 基準で全体を測り直すと、**現状のサイトは「受験生がこのサイトだけで基礎を完成できる」水準には届いていない**。クオリティを10→100で評価するなら、図形の性質が出たことで土台の説得力は上がったが、**全体平均は依然35前後**にとどまる。理由は3つに集約される。

1. **図解が2単元にしか存在しない。** diagram ブロックを使っているのは `geometry-properties`（15）と `quadratic`（6、有料版を含めると+3）だけ。**図・グラフが理解の生命線である単元（図形と計量・データの分析・図形と方程式・三角関数・微分積分・ベクトル・平面上の曲線）が、全て図解ゼロ**で文章だけになっている。これらは S 基準を満たしようがない。
2. **数学III・Cが完全に空。** `limits` / `differential-calculus` / `integral-calculus` / `complex-plane` / `curves` の5単元すべて `lessons: []`。理系受験生が最も必要とする科目が0講座で、サイトの信頼性を最も損なう。
3. **有料版がほぼ空。** 数学I・A有料版は `quadratic`（5講座）のみ実装、残り6単元は空。数学II・B・C有料版は10単元すべて空。基礎講座と有料版の役割分担が「文章としては定義されているが、中身がない」状態。

良い点として、**データ構造（`course.ts`）は完成度が高い**。`prerequisites` / `goals` / `lessonBlocks`（13種）/ `checkQuestions`（hint付き）/ `relatedPracticeLinks` / `qualityTags` が揃い、新しい型を足さずに S 品質を表現できる器がすでにある。実際、図形の性質は型を増やさずに S を達成した。**問題は器ではなく中身（特に図解と空単元）である。**

## 2. 高品質講座の基準（S の定義）

`geometry-properties` が満たしている要素を S 基準とする。

- 導入（`intro`）で「この講座で何を学ぶか・入試での重要性」が明確
- `prerequisites` と `goals` が具体的
- `formula` で公式を出すだけでなく、**`concept`（導出専用ブロック）で「なぜ成り立つか」を必ず説明**
- `comparisonTable` で **「図の特徴 → 意味 → 使う考え方」の読み替え表**を持つ
- `strategy` で典型パターンを3〜5個に整理
- `workedExample` が **段階別（例題A・基本／B・標準／C・入試基礎）** にタイトル付け
- 解説が「答え」でなく **「まず注目すること → なぜその定理か → 途中式 → 検算 → 時短」** の思考過程
- `commonMistake` が NG/OK/見分け方の形式
- `checkQuestions` が最低3問、全問 hint 付き、難度を段階配置
- **視覚が必要な単元では `diagram`（SVG図解）がある**
- 数式は KaTeX インライン（`$...$`）のみ、LaTeX コマンドは二重バックスラッシュ
- `qualityTags` が適切（`template-v2-complete` 等で達成判定可能）
- `relatedPracticeLinks` が2件以上

### 評価ランク定義

| ランク | 定義 |
|---|---|
| **S** | geometry-properties レベル。図解・読み替え表・段階別例題・NG/OK誤答・確認問題が全て揃う |
| **A** | 十分良い。導出・読み替え・段階別例題はあるが、図解または演習の追加で更に良くなる |
| **B** | 基礎講座として最低限はあるが、図解・導出・読み替え表のいずれかが不足 |
| **C** | 視覚が必須なのに図解が無い、または説明が公式紹介寄りで、この講座だけでは理解しきれない |
| **D** | 未実装、または大幅不足 |

## 8. 図解・グラフが不足している講座

> 重要構造的制約: 現状 `DiagramType`（`course.ts`）は **放物線系6種＋円・三角形の幾何系15種のみ**。三角関数・ベクトル・微分積分・統計などに図解を入れるには新しい `diagramType` の追加が必要。本監査の方針では新 diagramType 追加は今回スコープ外のため、下表は**次フェーズの実装対象**として洗い出す。

| 科目 | 単元 | 必要な図解 | 理由 | 優先度 |
|---|---|---|---|---|
| II・B・C | 三角関数 | 単位円、$y=\sin x$ 等のグラフ、合成 | 周期・符号・位相は図無しでは理解困難 | 高 |

## 12. 基礎講座と有料版の役割分担の問題

- **役割定義は明確だが実体が無い。** `index.ts` の description で「基礎＝教科書〜共通テスト〜標準入試／有料＝難関大・融合・記述」と書かれているが、有料版は I・A の quadratic（5講座）以外すべて空。**読者は有料版の価値を1単元でしか確認できない。**
- **基礎講座の「上級者(advanced)」レベルが有料版領域に踏み込んでいる。** 各単元 beginner3/standard3/advanced3 の機械的構成で、二次関数の advanced は旧帝大融合寄り。これは本来有料版の担当範囲と重複する。
  - **方針**: 基礎の advanced 最難問は「有料版へ移送する候補」とタグ付けし、無料は標準入試までに揃える。ただし**今回は slug/URL を壊さないため移送は実施せず、将来課題として記録**。
- **有料版の立ち上げ順**: 需要と差別化が出しやすい順に、二次関数(済)→微分積分→ベクトル→確率→整数→図形 が有効。難関頻出かつ「基礎との差」を見せやすい単元から。
