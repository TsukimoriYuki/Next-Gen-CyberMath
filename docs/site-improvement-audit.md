# Next-Gen-CyberMath 総合改善監査レポート

作成日: 2026-06-17

## 1. 総評

Next-Gen-CyberMath は、数学講座、サイバー模試、本番レベル模試集、共通テスト対策室、英語速読長文まで広く含む、かなり意欲的な受験勉強サービスになっている。特に、数学講座を静的 TypeScript データで体系化している点、数学I・A有料版に二次関数の発展講座を追加できている点、英語速読長文に WPM 基準のスピードサポートを入れている点は、単なる問題集サイトより一段強い。

一方で、受験生が毎日使うサービスとして見ると、いくつかの信頼性・可読性・導線の課題が残っている。最も優先度が高いのは、`npm run lint` が 32 errors / 19 warnings で失敗していること、`/math` ページでデスクトップ・スマホとも横スクロールが発生すること、本番レベル模試の採点・復習導線がまだ学習成果につながりにくいこと、英語ページのライトテーマ化が広い CSS 上書きに依存していること。これらは、機能追加より先に整えるとサイト全体の信頼感が上がる。

調査は、コード確認とローカル実画面確認の両方で行った。主に確認したディレクトリ・ファイルは次の通り。

- `src/app/page.tsx`, `src/app/math/page.tsx`, `src/app/courses/**`, `src/app/exam-sets/**`, `src/app/english/**`, `src/app/common-test/**`, `src/app/mock/page.tsx`
- `src/components/courses/**`, `src/components/exam-sets/ExamSetRunner.tsx`, `src/components/english/SpeedReadingGame.tsx`, `src/components/english/SpeedSupportReader.tsx`
- `src/data/courses/**`, `src/data/exam-sets.ts`, `src/data/exam-sets/standard-private-math-1a-001.ts`, `src/data/english-speed-reading*.ts`
- `src/lib/english-types.ts`, `src/lib/exam.ts`, `src/lib/common-test-answer-normalize.ts`, `src/types/course.ts`, `src/app/globals.css`

実画面では、`/`, `/math`, `/courses`, `/courses/math-1a-premium`, `/exam-sets`, `/english/speed-reading`, `/english/speed-reading/ai-and-environment?speedSupport=1` をデスクトップ幅で確認し、さらに 390x844 のスマホ幅で `/math`, `/courses`, `/exam-sets/standard-private/math-1a/standard-private-math-1a-001`, `/english/speed-reading`, `/english/speed-reading/ai-and-environment?speedSupport=1` を確認した。

検証結果は次の通り。

- `npm run build`: 成功。Prisma 同期、Prisma Client 生成、Next.js production build、TypeScript、1134ページ生成まで完了。ただし Node の `module.register()` deprecation warning は出ている。
- `npm run lint`: 失敗。51 problems。内訳は 32 errors / 19 warnings。
- 今回の軽微修正: なし。コードは変更せず、監査レポートのみ作成した。

## 3. UI / UX の改善点

トップページは、数学・英語・共通テストの3入口が大きく、初見でも「科目を選ぶ」ことは分かりやすい。数学ホームでは、過去問道場、サイバー模試、本番レベル模試集、講座、単元一覧がカードで整理されており、数学領域の機能は見つけやすい。

ただし、受験生目線では「今日は何をするべきか」というタスク起点の導線がまだ弱い。トップから直接「講座を進める」「模試を受ける」「速読をする」「復習する」を選べると、継続利用の入口が明確になる。

また、実画面確認で `/math` に横スクロールが出ていた。デスクトップ幅では `scrollWidth` が `clientWidth` を超え、スマホ幅でも難易度ピラミッド付近のカードがはみ出していた。学習サイトでは横スクロールはかなり体験を損ねるため、早めに直したい。

カードUIは情報量が豊富で、機能の多さを伝えられている。一方、重要CTAと説明文が同じカード内でやや密になっている箇所もある。特にスマホでは、カード内の「何ができるか」と「押すボタン」をより近く配置すると操作が軽くなる。

## 4. 数学講座の改善点

講座集は `通常講座` と `発展講座・有料版` に分かれており、無料版と有料版を別カテゴリとして扱う方針は守られている。`数学IA` は 7単元63講座、`数学II・B・C` は 10単元90講座として表示され、科目別の学習入口としてはかなり充実している。

無料講座は、`LessonBlock` に `intro`, `concept`, `formula`, `diagram`, `stepByStep`, `comparisonTable`, `workedExample`, `commonMistake`, `strategy`, `checkpoint`, `practice`, `summary`, `nextStep` が用意されており、ただの文章データではなく、講義UIとして拡張しやすい構造になっている。KaTeXも `CourseBodyRenderer` と `MathText` を通して扱われているため、通常の数式表示方針は整理されている。

改善すべき点は、講座から演習への接続である。データ上は `relatedPracticeLinks` が豊富に入っているが、講座ページでは表示されていない。これにより、「読んだあと何を解けばよいか」が画面に出ない。受験生向けサービスとしては、講義、確認問題、関連演習、復習キューまでを1本につなげると効果が大きい。

また、`数学III・C` が5単元0講座で表示される。準備中として扱うならカード上でもその旨を明確にし、無料版・有料版と同じく「今後追加予定」が分かる形にしたい。

## 5. 有料版講座の改善点

`数学I・A 有料版` と `数学II・B・C 有料版` は、通常講座とは別データとして分離されている。`math-1a-premium`, `math-2bc-premium` の slug も既存無料版を壊さない形で整理されている。

数学I・A有料版の二次関数は、最初の5講座が実装済みだった。

- `quadratic-premium-overview`
- `quadratic-premium-graph-basics`
- `quadratic-premium-square-completion`
- `quadratic-premium-max-min-basic`
- `quadratic-premium-max-min-parameter-intro`

内容は、問題文の読み替え、条件翻訳、グラフ・方程式・不等式・最大最小の接続、場合分けの境界値などを扱っており、無料版との差別化はできている。特に「いきなり計算しない」「何を問われているか分類する」という指導は、難関大レベルの土台としてよい。

一方で、科目ページでは `準備中` バッジが出ているのに、二次関数は5講座開ける。この状態は「有料版は準備中なのか、一部公開なのか」が曖昧に見える。科目全体は「一部公開・順次追加」、未実装単元は「準備中」と分けるのが自然。

また、今後追加予定の二次関数講座IDはデータにあるが、画面には出ていない。発展講座はロードマップが価値になるため、単元ページに「今後追加予定」として表示したい。

今後追加優先度が高い二次関数テーマは次の通り。

- 解の配置と判別式
- 文字係数を含む最大最小の発展
- 二次不等式と恒成立・存在条件
- 直線との共有点・接線
- 絶対値付き二次関数
- 整数条件を含む二次関数
- 場合分け設計だけを集中的に扱う講座
- 入試実戦セットと答案作成講座

## 6. 本番レベル模試集の改善点

`/exam-sets` では、サイバー模試と本番レベル模試集の違いがカードで説明されている。これは良い。`サイバー模試` はタグ・難易度・時間を自由に指定する演習、`本番レベル模試集` は固定模試という違いが伝わる。

カテゴリは次の4つ。

- 中堅私立模試
- 上級私立模試
- 中堅国公立模試
- 難関国公立模試

現状、公開中の固定模試は `standard-private-math-1a-001` の1本。60分、100点満点、想定平均35〜45点、小問数20問で、中堅私立数学I・Aとしては構成が分かりやすい。問題は、小問集合、二次関数、図形と計量、場合の数と確率に分かれており、対象レベルとも大きく外れていない。

課題は採点と復習である。穴埋めを数字単位に分けることで式入力を避ける方針は守られているが、採点は文字列一致中心で、将来的な別解や表記ゆれには弱い。また、提出後は正誤と解説が見えるものの、弱点タグ、復習順、関連講座への接続がない。模試は「受ける」より「復習する」価値が大きいため、採点後UIの強化を優先したい。

スマホ幅では入力欄は縦に並び、横スクロールは発生しなかった。ただし20個の入力欄が続くので、未入力数、セクションジャンプ、提出前チェックがあると使いやすい。

## 7. 英語速読長文・スピードサポートの改善点

速読長文は、教科書、共通テスト、私立大、国公立大の4レベルに分かれている。各レベルカードには `通常で読む` と `スピードサポートで読む` があり、本文に入る前にモードを選ぶ導線は実装されている。`?speedSupport=1` で本文ページに入ると、スピードサポートUIが表示され、タイマーも自動開始することを確認した。確認時点では、約2秒後に `経過: 0:03` となり、`目標WPM: 150` も共通テストモードで維持されていた。

WPMロジックも、`targetWordsRead = Math.floor((elapsedSeconds / 60) * targetWpm)` の考え方で実装されている。本文は文単位に分割され、累積語数から現在文を決める構造になっている。本文以外のUI文字色も、スピードサポート情報カードでは `text-slate-900` 系で読める状態になっている。

改善点は大きく3つある。

1. レベルカードからランダムに問題へ飛ぶため、実質的な「長文一覧」になっていない。復習や選択学習には、長文一覧カードが必要。
2. `現在WPM` は実測ではなく目標WPMの目安として表示されている。読者の実読位置を入力しない限り、ラベルは `目標ペース` などが自然。
3. スピードサポート中も通常の `Reading Time` タイマーと WPM パネルのタイマーが併存する。制限時間タイマーと目標読了時間の関係を整理しないと、受験生がどちらを見ればよいか迷う。

収録数は `COMMON_TEST` 21、`NATIONAL_UNI` 18、`PRIVATE_UNI` 16、`TEXTBOOK` 1。共通テスト・私大・国公立はある程度あるが、教科書レベルが薄い。英語が苦手な受験生の入口として、教科書レベルの短文を増やす価値が高い。

## 8. モバイル対応の改善点

390x844 のスマホ幅で確認した範囲では、講座集、模試、スピードサポート本文ページは大きく崩れていなかった。スピードサポートUIも縦積みで表示され、進捗バーとボタンは横スクロールなしで確認できた。

ただし、`/math` ではスマホでも横スクロールが発生している。原因は難易度ピラミッドのカードと、ホバー演出のシマー要素。サイトの入口に近いページなので優先修正したい。

本番レベル模試は、スマホで入力欄が読める一方、長い試験を縦スクロールだけで進めるには負担が大きい。固定ヘッダーのタイマーは良いが、セクションナビ、未入力数、提出前確認、現在セクションの表示があるとさらに使いやすい。

英語速読は、本文の行間は読みやすい。スピードサポートUIは情報量が多いので、スマホでは統計カードを折りたたむか、「目標WPM・経過・目安語数・残り」だけを上部に固定表示する案もある。

## 9. アクセシビリティの改善点

ライトテーマの主要ページは、基本的に `text-slate-*` 系で読みやすい。一方で、英語ページは旧ダークUIのクラスを `english-academic` で強制的にライト化しているため、将来的に意図しない色反転や低コントラストが再発しやすい。

disabled ボタンは読める箇所が多いが、機能全体で統一されていない。`準備中` のような非アクティブ状態は、色だけでなくテキストでも明確に伝えるべき。

アイコンが多いUIでは、アイコンの意味をテキストが補っている箇所が多く、方向性は良い。ただし、aria-label や見出し階層の整備、キーボード操作時のフォーカス表示は追加確認が必要。

## 10. コンテンツ品質の改善点

数学講座は、初学者向けでも「なぜその式変形をするか」を説明する姿勢があり、受験生向けとして良い。二次関数有料版は、単なる公式解説ではなく、条件翻訳や方針判断を中心にしており、無料版との差別化ができている。

今後の課題は、演習量と品質検査である。講義がよくても、確認問題が少ないと定着しにくい。特に有料版は、講義1本につき少なくとも3段階の問題を用意すると価値が上がる。

模試の解説は、現状では正答確認としては機能しているが、復習教材としてはまだ薄い箇所がある。なぜその方針になるか、どこでミスしやすいか、別解や検算はあるか、関連講座はどれか、まで出せると受験生に刺さる。

英語速読は、英文本文と設問解説が揃っている。次の段階では、読後の語彙、段落要約、根拠文ハイライト、読み直しポイントを足すと、WPM練習と読解力向上がつながる。

## 13. 追加すると差別化できる機能案

- WPM診断: 速読長文の読了時間と正答率から、速度型・精度型・読み飛ばし型を判定する。
- 数学の答案作成モード: 方針、式変形、結論を段階的に書く練習。
- 講座から模試への自動推薦: 間違えた模試問題に応じて、関連講座を表示。
- 二次関数ケース分けトレーナー: 軸と区間の位置関係をドラッグで確認する。
- 模試後の復習シート自動生成: 間違えた問題、原因、次に解く問題を1ページにまとめる。
- 英語長文の根拠文ハイライト: 設問ごとに根拠文を本文中で表示。
- 共通テスト時間配分シミュレーター: 大問別の目標時間と実績を比較。
- 有料版ロードマップ表示: 公開済み、次回追加、準備中を単元ごとに表示。
- 講座品質チェックダッシュボード: 空リンク、KaTeXエラー、確認問題数不足を一覧化。

## 14. まとめ

Next-Gen-CyberMath は、すでに教材データ・演習・模試・英語速読がそろい始めており、受験勉強サービスとしての核はかなり強い。特に、数学講座の構造化と、英語速読のWPMスピードサポートは差別化要素になる。

次の一手は、新機能を増やすことよりも、学習者が迷わず使える導線、復習までつながる模試、横スクロールやlintエラーのない安定感を整えること。受験生は「このサイトなら毎日使って大丈夫」と感じたときに定着する。その信頼感を作るために、まずは High 優先度の課題から潰すのがよい。
