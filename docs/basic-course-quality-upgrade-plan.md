# 基礎講座クオリティ100化 改善計画

作成日: 2026-06-17
対象: `src/data/courses/**`（数学I・A / 数学II・B・C / 数学III・C）

---

## 1. 総評

現状の数学講座は「ゼロではない」が、「受験生がこのサイトだけで基礎を完成できる」水準には届いていない。クオリティを10→100で評価するなら、**現状は20前後**。内訳は次の通り。

- **構造（データ設計）は優秀（80点）**。`CourseLesson` は `prerequisites` / `goals` / `lessonBlocks`（13種）/ `checkQuestions` / `relatedPracticeLinks` / `qualityTags` を持ち、本計画が目指す「理想テンプレート」をほぼそのまま表現できる器がすでにある。新たな型追加なしで深い講座を作れる。
- **網羅性は中（40点）**。数学I・A 7単元63講座、数学II・B・C 10単元90講座は入口として悪くない。しかし **数学III・C は5単元すべて0講座（完全な空）**、数学I・Aは **「図形の性質」単元がまるごと欠落**。
- **深さは不均一で、平均すると不足（25点）**。「二次関数」だけが本格化済み（1講座あたり約11,500バイト）で、導出・図解・場合分け・条件翻訳まで丁寧。一方、**他の全単元は1講座あたり約5,000〜7,500バイトと約半分**の分量にとどまり、公式紹介＋例題1〜2問で終わりがちな講座が多い。
- **問題演習は量だけある（35点）**。各講座に確認問題が約3問、例題（workedExample）が約2.5個入っている。数自体はあるが、「基礎確認／標準／入試基礎／発展橋渡し」の段階設計にはなっておらず、難度のばらつきが大きい。

良い点を潰さず、悪い点（空単元・薄い講座・段階設計の欠如）を埋めれば、土台は十分に強い。本計画は**全面書き換えではなく、二次関数で確立済みの「深い講座テンプレート」を全単元へ横展開する**ことを軸にする。

## 2. 「通常講座」から「基礎講座」への名称変更方針

### 方針

- **表示名のみ変更**し、内部 `subjectId` / `unitId` / `lessonId` / URL（`/courses/math-1a` 等）は一切変えない。slug変更はリンク切れ・SEO・ブックマーク破壊のリスクが高く、便益に見合わない。
- 「通常講座」という呼称は「無料版」「標準」という消極的な意味に読めるため、**「受験数学の土台を固める基礎講座」**という積極的な位置づけに改める。
- 「基礎講座」は**教科書レベルで止めない**。共通テスト・標準私大・標準国公立の二次までに必要な「典型問題の解法選択」「公式の意味」「条件翻訳の入口」までを担当範囲とする。難関大の複雑な場合分け・融合・記述は有料版／発展講座へ寄せる。

### 今回実施済みの軽微修正

`src/app/courses/page.tsx` の表示文言3箇所を変更（slug・データ・URLは不変）:

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| metadata.description | 「…通常講座と、有料版の発展講座を…」 | 「…基礎講座と、有料版の発展講座を…」 |
| ヘッダー説明文 | 「…通常講座と、今後追加予定の…」 | 「…受験数学の土台を固める基礎講座と、今後追加予定の…」 |
| セクション見出し | `title="通常講座"` | `title="基礎講座"` |

### 今後の表示名整理（本計画では未実施）

- 各 `CourseSubject.description` を「単元の列挙」から「この基礎講座で到達できる地点」を語る文へ書き換える（例: 数学IA「数と式から確率まで、共通テスト・標準入試で問われる典型解法を、公式の意味から理解する基礎講座」）。
- 現状の3レベルラベル（初学者／中級者／上級者）は基礎講座内の難度段階として維持しつつ、「上級者」レベルの最難問（例: 二次関数「旧帝大レベル融合問題の切り崩し」）は将来的に有料版へ移送する候補とする。

## 3. 現在の講座の問題点

厳しめに列挙する。

1. **数学III・Cが完全に空**。`limits` / `differential-calculus` / `integral-calculus` / `complex-plane` / `curves` の5単元すべて `lessons: []`。理系受験生にとって最重要の科目が0講座であり、サイトの信頼性を最も損なっている。
2. **数学I・Aに「図形の性質」単元が存在しない**。チェバ・メネラウス、円周角・接弦角・方べきの定理、五心などは共通テスト・私大で頻出だが、講座が一切ない。
3. **深さが二次関数に偏在**。二次関数だけが導出・図解・場合分け・条件翻訳まで本格化済み（約11.5k bytes/講座）。残り全単元は約半分の分量で、「公式→例題1〜2→確認問題3」の薄いパターンに陥りがち。
4. **「なぜそうなるか（導出）」が体系化されていない**。`formula` ブロックは公式を提示するが、導出・背景を必ず添える運用にはなっていない。暗記講座になりかけている単元がある。
5. **「問題文の読み替え」ブロックが弱い**。「最大値を求めよ→頂点と端点を比較」「すべての実数で成り立つ→恒成立→判別式」のような**表現→方針の変換表**が、二次関数以外ではほとんど整備されていない。`strategy` ブロックは全体で47個（153講座中）と少ない。
6. **例題に段階ラベルがない**。`workedExample` は多いが「基本／標準／入試基礎／ひねり」の段階が設計されておらず、難度が講座ごとにバラバラ。
7. **確認問題が段階設計でない**。各講座3問はあるが「基礎確認1／標準1／入試基礎1／発展橋渡し1」の意図的配分になっていない。
8. **詰め込みすぎの単元がある**。「場合の数と確率」が1単元、数学IIの「微分法・積分法」が `calculus-2` 1単元、数学III・Cの「式と曲線」が二次曲線＋媒介変数＋極座標を1単元に圧縮。分割が必要。
9. **関連演習が表示されていない**（既知の別課題）。`relatedPracticeLinks` はデータに約2件/講座入っているが講座ページ未表示。データはあるので、深さ強化と同時に表示導線を整えると効果が大きい。
10. **有料版との役割境界が曖昧**。基礎講座の「上級者」レベルが旧帝大融合問題まで踏み込んでおり、有料版の領域と重複している。

## 4. 基礎講座の理想テンプレート

各講座は最終的に以下11ブロック構成を目標とする。括弧内は対応する既存 `LessonBlockKind`／`CourseLesson` フィールド。**新しい型は不要**で、既存構造で表現できる。

| # | ブロック | 内容 | 対応する既存フィールド |
|---|---|---|---|
| 1 | この講座で学ぶこと | 何を学ぶか／入試での重要性／どの問題につながるか | `intro` ＋ `goals` |
| 2 | 前提知識 | 前に理解すべき内容・既習単元へのリンク | `prerequisites` ＋ `nextStep`(逆向き) |
| 3 | 基本概念 | 定義・公式・図形的/グラフ的意味・条件の意味 | `concept` / `formula` / `diagram` |
| 4 | なぜそうなるか | 公式の導出・考え方の背景（暗記回避） | `concept`（導出専用）/ `formula.emphasis` |
| 5 | 問題文の読み替え | 表現→意味→使う公式・方針への変換表 | `comparisonTable`（読み替え表）/ `strategy` |
| 6 | 典型パターン（3〜5個） | 基本計算型／条件翻訳型／場合分け型／グラフ利用型／入試標準型 | `strategy` / `comparisonTable` |
| 7 | 例題（段階別） | 基本／標準／入試基礎／少しひねった例題 | `workedExample`（titleに段階を明記）|
| 8 | 詳しい解説 | 注目点→方針選択の理由→途中式の意味→別解→検算→時短 | 各 `workedExample.body` ＋ `strategy` |
| 9 | よくある誤答 | 定義域見落とし／場合分け境界／必要十分混同／符号落ち等 | `commonMistake` |
| 10 | 確認問題（3問以上） | 基礎確認1／標準1／入試基礎1／(発展橋渡し1) | `checkQuestions`（hint付き）|
| 11 | 関連演習 | 共通テスト／本番レベル模試／サイバー模試／関連講座／有料版 | `relatedPracticeLinks` |

### テンプレート運用ルール（品質基準）

- 1講座あたり**分量の下限を約10,000バイト相当**（二次関数の現行水準）とする。現状の薄い単元は約2倍に増量が必要。
- `formula` ブロックは**必ず導出または直観的説明を併記**（ブロック4を省略しない）。
- 各講座に **`comparisonTable` で「読み替え表」を最低1枚**入れる（ブロック5）。
- `workedExample` は **titleに段階を明記**（例「例題A・基本」「例題D・入試基礎」）。
- `checkQuestions` は**最低3問**、難度を段階配置し、全問に `answer` と `hint`。
- `relatedPracticeLinks` は**最低2件**、講座ページで表示する（別途UI対応）。
- `qualityTags` に `template-v2-complete` 等の達成タグを付け、未達講座を機械的に抽出できるようにする。

## 5. 数学I・Aの不足単元・改善案

> 現状: 7単元63講座。各単元9講座（初学者3／中級者3／上級者3）。二次関数のみ本格化済み。

### 5.1 数と式
- **現状**: 9講座。整式・展開・因数分解・実数・絶対値・1次不等式を扱う想定。分量 約5.3k/講座と薄め。
- **問題**: 対称式・交代式、二重根号、絶対値を含む方程式・不等式の場合分けが手薄になりやすい。導出より公式列挙に寄りがち。
- **改善**: 「対称式と基本対称式」「二重根号の外し方」「絶対値の場合分け（定義に戻る）」を独立講座化。各講座に読み替え表（例「|x|を含む→定義で場合分け／2乗して同値性確認」）。
- **評価**: 問題数=やや不足 / 解説の深さ=標準 / 網羅性=中

### 5.2 集合と命題
- **現状**: 9講座。集合演算・命題・必要十分・対偶・背理法。
- **問題**: 受験生の最頻出ミス「必要条件と十分条件の混同」を扱う専用ブロックが弱い。ド・モルガンや「すべて／ある」の否定の機械化が不足しがち。
- **改善**: 「必要・十分の判定手順（→ならば矢印で図示）」「全称・存在の否定」「対偶・背理法の使い分け」を強化。`commonMistake` を必ず2件以上。
- **評価**: 問題数=やや不足 / 解説の深さ=標準 / 網羅性=中

### 5.3 二次関数
- **現状**: 9講座、**本格化済み**（とは何か／平方完成／最大最小基本／定義域つき最大最小／文字含む場合分け／方程式・不等式接続／条件翻訳／パラメータ最大最小／旧帝大融合）。本サイト最良の単元。
- **問題**: それでも**基礎講座としては粒度が粗い**。「二次不等式」「判別式」「グラフと直線の共有点」「解の配置」「絶対値付き二次関数」が独立講座になっておらず、複数テーマが1講座に同居している。最上級講座（旧帝大融合）は有料版相当。
- **改善（分割）**: 下記の10粒度へ展開（詳細は §10）。基礎講座側は「二次不等式」「判別式と共有点」「解の配置（基礎）」までを担当、複雑な解の配置・絶対値の融合は有料版へ。
- **評価**: 問題数=適切 / 解説の深さ=深い / 網羅性=中（粒度を上げれば高）

### 5.4 図形と計量
- **現状**: 9講座。三角比・正弦定理・余弦定理・面積・空間図形。
- **問題**: 「どの定理をいつ使うか」の選択フロー（2辺と挟角→余弦定理、など）が読み替え表になっていない。測量・空間への応用が薄い。
- **改善**: 「定理選択フローチャート（`diagram`/`comparisonTable`）」を追加。「空間図形への正弦・余弦の持ち込み」を独立講座化。
- **評価**: 問題数=やや不足 / 解説の深さ=標準 / 網羅性=中

### 5.5 データの分析
- **現状**: 9講座。代表値・分散・標準偏差・相関・箱ひげ。
- **問題**: **共通テスト最頻出なのに分量が最も薄い部類（約5.7k）**。相関係数の意味・外れ値・仮説検定の入口（新課程）が手薄。計算過程の読み取り問題への対応が弱い。
- **改善**: 「相関係数の意味と誤解」「分散・標準偏差の計算を速くする」「データの変換（平均・分散の変化）」「仮説検定の考え方（入口）」を強化。共通テスト型の読み取り例題を増量。
- **評価**: 問題数=不足 / 解説の深さ=浅い〜標準 / 網羅性=低〜中 → **最優先級**

### 5.6 場合の数
- **現状**: 「場合の数と確率」**1単元に同居**（9講座）。順列・組合せ・重複・円順列など。
- **問題**: 確率と詰め込みのため、場合の数側の「区別する／しない」「同じものを含む順列」「組分け」の典型が浅くなりがち。
- **改善**: §10で「場合の数」と「確率」を別単元に分割。場合の数側に「数え上げの3原則」「重複組合せ」「組分けの典型」を配置。
- **評価**: 問題数=やや不足 / 解説の深さ=標準 / 網羅性=中

### 5.7 確率
- **現状**: 同上、同居単元内。独立試行・条件付き確率・期待値。
- **問題**: 条件付き確率・独立の判定・反復試行が、場合の数と同居のため講座数を取り合っている。期待値の意味づけが弱い。
- **改善**: 確率を独立単元化し、「条件付き確率と独立」「反復試行」「期待値の意味と計算」「確率漸化式の入口」を増設。
- **評価**: 問題数=やや不足 / 解説の深さ=標準 / 網羅性=中

### 5.8 整数の性質
- **現状**: 9講座。約数・倍数・余り・ユークリッド互除法・不定方程式・記数法。
- **問題**: 「合同式の入口」「不定方程式の一般解の書き方」「余りで分類する発想」の導出が薄いと暗記になりやすい。
- **改善**: 「割り算の原理と余りの分類」「ユークリッド互除法の意味（なぜ最大公約数が出るか）」「一次不定方程式の解法手順」を導出付きで強化。
- **評価**: 問題数=やや不足 / 解説の深さ=標準 / 網羅性=中

### 5.9 図形の性質
- **現状**: **単元が存在しない（0講座）**。
- **問題**: 円周角・接弦角・方べきの定理、チェバ・メネラウス、三角形の五心、内接・外接円は共通テスト・私大頻出。**最大の網羅性の穴**。
- **改善**: 新単元 `geometry-properties` を新設し、最低6講座: 「三角形の五心」「チェバ・メネラウスの定理」「円周角と接弦角」「方べきの定理」「内接四角形・接線」「空間図形の基本（多面体・オイラー）」。
- **評価**: 問題数=なし / 解説の深さ=なし / 網羅性=**ゼロ** → **新規最優先**

## 6. 数学II・B・Cの不足単元・改善案

> 現状: 10単元90講座。全体に分量約4.9〜6.0k/講座で**基礎講座としては浅め**。

### 6.1 式と証明
- **現状**: 9講座（約4.9k＝最薄）。二項定理・整式の割り算・恒等式・等式/不等式の証明・相加相乗。
- **問題**: 相加相乗平均の等号成立条件、コーシー・シュワルツの入口、証明の「型」が薄い。最薄単元。
- **改善**: 「恒等式の決定（係数比較・数値代入の使い分け）」「不等式証明の型（差をとる／2乗／相加相乗）」を読み替え表付きで増量。
- **評価**: 問題数=不足 / 解説の深さ=浅い / 網羅性=中 → **優先**

### 6.2 複素数と方程式
- **現状**: 9講座。複素数計算・解と係数の関係・剰余/因数定理・高次方程式。
- **問題**: 解と係数の関係の活用、共役解、組立除法の意味づけが薄くなりやすい。
- **改善**: 「解と係数の関係の使いどころ」「高次方程式の因数分解戦略」「共役複素数解の性質」を強化。
- **評価**: 問題数=やや不足 / 解説の深さ=標準 / 網羅性=中

### 6.3 図形と方程式
- **現状**: 9講座。点と直線・円・軌跡・領域。
- **問題**: 軌跡・領域は受験生が最も苦手。「条件→式→軌跡」の翻訳プロセスと、領域における最大最小（線形計画）が薄い。

## 11. 各講座に追加すべき共通ブロック

現在ばらつきのある講座を、§4テンプレートに揃えるため、**全講座へ以下を最低ラインとして補う**。

1. **導出ブロック（ブロック4）**: すべての `formula` に「なぜこの公式が成り立つか」を `concept` で併設。暗記禁止。
2. **読み替え表（ブロック5）**: `comparisonTable` で「問題文の表現 → 意味 → 使う公式・方針」を最低1枚。例:
   - 「最大値を求めよ → 頂点と定義域の端点を比較」
   - 「共有点をもつ → 実数解の個数 → 判別式」
   - 「すべての実数xで成り立つ → 恒成立 → 最小/最大・判別式」
3. **典型パターン表（ブロック6）**: 3〜5型を `strategy`／`comparisonTable` で明示（基本計算型・条件翻訳型・場合分け型・グラフ利用型・入試標準型）。
4. **段階別例題（ブロック7・8）**: `workedExample` を「基本／標準／入試基礎／ひねり」でラベル付けし、解説に「注目点→方針理由→途中式の意味→別解→検算→時短」を含める。
5. **よくある誤答（ブロック9）**: `commonMistake` を**最低1件、頻出単元は2件**。定義域・場合分け境界・必要十分・符号・解範囲。
6. **段階別確認問題（ブロック10）**: `checkQuestions` を基礎確認1／標準1／入試基礎1（＋発展橋渡し1）。全問 `hint` 付き。
7. **関連演習（ブロック11）**: `relatedPracticeLinks` を最低2件（共通テスト／本番レベル模試／サイバー模試／関連講座／有料版）。**講座ページでの表示UIも整備**。

## 15. まとめ

現状の数学講座は、**データ構造は優秀、二次関数は本格的、しかし網羅性と深さに重大な穴がある**。最大の問題は次の3点。

1. **数学III・Cが完全に空**（理系受験の根幹が0講座）。
2. **数学I・Aに「図形の性質」単元が欠落**（共通テスト頻出領域の穴）。
3. **二次関数以外の全単元が約半分の分量**で、導出・読み替え・段階設計が不足。

幸い、器（`LessonBlock` 13種・`prerequisites`・`checkQuestions`・`relatedPracticeLinks`）は理想テンプレートをそのまま表現でき、二次関数という**到達点の見本**も既にある。やるべきは新規の大発明ではなく、**「二次関数で確立した深い講座テンプレートを、空単元の新設と薄い単元の増量へ横展開する」**こと。

まずは Phase 1（表示名変更・テンプレ明文化・関連演習表示）を終え、§14の5講座から着手すれば、クオリティ10→100への道筋を、既存資産を壊さずに最短で進められる。
